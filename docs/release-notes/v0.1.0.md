First public release of Drawspace, a native Android sketching app for tablets with a stylus.

### Highlights

- **Infinite canvas** and **fixed-size artboards**, with presets for tablet screen, Full HD, 4K, Square 2K, A4 and US Letter at 300 DPI, or a custom size.
- **Low-latency stylus input** on OpenGL ES 3.0 with front-buffered rendering, pressure, tilt, motion prediction and palm rejection.
- **Tools:** pen, pencil, marker, straight line with grid and 15° angle snapping, bucket fill, and eraser.
- **Color:** HSV color picker and a customizable palette.
- **Canvas backgrounds:** blank, dot grid, grid, lined, isometric, and crosses.
- **Themes:** Light, Dark and AMOLED Black, plus per-canvas overrides.
- **Storage:** crash-safe write-ahead log with a Git repository per workspace, undo/redo that survives restarts, and a visual checkpoint history.
